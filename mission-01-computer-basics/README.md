## 4. My understanding

### Task 1.1 — Trace one activity using IPOS
**Chosen Activity:** Typing Python code into an editor and saving it to the computer.

| Stage | What happens in your example? | Possible hardware / component |
| :--- | :--- | :--- |
| **Input** | I press keys on my keyboard to write code and click the save button with my mouse or trackpad. | Keyboard, Mouse / Trackpad |
| **Processing** | The CPU takes the keystrokes, calculates which letters were typed, and keeps them in memory (RAM) while the editor is open. | CPU (Processor) and RAM (Memory) |
| **Output** | The screen displays the letters as I type them so I can see my code right away. | Monitor / Display Screen |
| **Storage** | When I press save, the computer writes the file onto the SSD so it stays there even after I shut down the laptop. | Solid State Drive (SSD) |

**How the activity flows:**
When I start typing, the keyboard sends input signals into the computer. The processor (CPU) receives these signals, figures out what letters they correspond to, and temporarily stores them in the computer's working memory (RAM). At the same time, the computer outputs those letters onto the monitor so I can see what I am writing in real time. When I click save or press Ctrl+S / Cmd+S, the processor copies the data from temporary RAM into permanent storage on the SSD, so my file is preserved for later.

## 5. Difficulties faced
At first, it was a little confusing to decide whether Terminal counted as an application or a utility.

## 6. How I resolved them
I realized that regular applications (like Chrome or VS Code) are tools you use for day-to-day user tasks, while utilities (like Terminal or Activity Monitor) are used to manage, configure, or inspect the computer system itself.
