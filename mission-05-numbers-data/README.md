### Task 5.3 — Build a small number converter
The converter script `number_converter.py` prompts the user for an integer in decimal format, parses it into an integer, and formats it using Python's built-in `bin()` and `hex()` functions.

**Test Results:**

| `13` | `0b1101` | `0xd` |
| `42` | `0b101010` | `0x2a` |
| `255` | `0b11111111` | `0xff` |

**Function Explanations:**
- `bin(number)`: Converts an integer into a binary string prefixed with `0b`. It represents the exact bit pattern of the integer in base-2.
- `hex(number)`: Converts an integer into a lowercase hexadecimal string prefixed with `0x`. It groups every four binary bits into a single hexadecimal character in base-16.

### Task 5.4 — How is text stored?
- **ASCII decimal codes:**
  - Uppercase letter `A`: `65` (binary `01000001`)
  - Lowercase letter `a`: `97` (binary `01100001`)
- **Why a computer needs an encoding standard:**
  Computers and digital hardware operate exclusively on binary electrical states (bits: 0s and 1s) and cannot natively comprehend human letters or symbols. An encoding standard defines an agreed mapping table that associates each character with a specific numeric binary code so systems can reliably save, transmit, and render identical text across different hardware and software.
- **Example of a character outside basic ASCII:**
  The Indian Rupee symbol (`₹`, Unicode `U+20B9`) or Euro symbol (`€`, Unicode `U+20AC`). Basic ASCII only supports 128 characters (0–127) covering the English alphabet, numbers, and basic punctuation, so international currency signs require multi-byte UTF-8 encoding.
